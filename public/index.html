Why KnightBot-Mini

A fast, lightweight WhatsApp MD bot

Built on the Baileys library and engineered for stability, KnightBot-Mini gives you full control with modular commands and easy customization.

🔓

Fully Open Source

The entire codebase is editable. Fork it, rebrand it, host it anywhere — Render, Heroku, a VPS, or a panel. No permission required.

🧩

Modular Commands

Commands live in the commands/ folder. Add, edit, or remove features without ever touching the core engine.

⚡

RAM-Optimized

Streaming media handling, temp cleanup, and bounded in-memory stores keep the bot light — perfect for Render's 512MB free tier.

🎨

Easy Customization

Change the bot image, prefix, name, and newsletter via simple in-chat commands. Or use our Config Builder before you deploy.

🔗

Pair-Code Login

No QR scanning in a terminal. Generate a pairing code here, link your WhatsApp via Linked Devices, and get a session string instantly.

🛡️

Group Protection

Antilink, antitag, antibadword, welcome/goodbye, anticall and more — a complete moderation toolkit right out of the box.

📊

Multi-Hosting Dashboard

Run multiple bot instances from one dashboard. Create, start, stop, and restart each bot independently — every bot gets its own isolated process and session.

📋

Live Logs & Auto-Restart

Watch real-time logs per bot from the dashboard. Bots that crash unexpectedly auto-restart themselves, so your WhatsApp stays online around the clock.

Step 3 · Go Live

        
Deploy to Render

        
Render runs your bot as a Node web service on a free instance. Follow these steps and you'll have a 24/7 bot online in minutes.

      


      

        

          
1

          

            
Fork the repository

            
Create your own copy of KnightBot-Mini under your GitHub account.

            → Fork on GitHub
          

        

        

          
2

          

            
Sign in to Render

            
Create a free Render account and connect your GitHub account so Render can see your fork.

            → Render Dashboard
          

        

        

          
3

          

            
Create a Web Service

            
In Render, click New → Web Service, select your KnightBot-Mini fork, and use these settings:

            

              Build: npm install

              Start: node index.js

              Plan: Free
            

          

        

        

          
4

          

            
Add environment variables

            
In the Environment tab, add SESSION_ID with your KnightBot!... session string from Step 1. Optionally add the other vars from the Config Builder above.

          

        

        

          
5

          

            
Deploy

            
Click Create Web Service. Render installs dependencies and starts your bot. Watch the logs — you'll see ✅ Bot connected successfully!

          

        

        

          
6

          

            
Keep it alive (optional)

            
Render's free tier sleeps after inactivity. Use a free uptime monitor like UptimeRobot to ping your bot's URL every 5 minutes.

          

        

      


      

        
Prefer one-click deploy?

        
Use Render's blueprint. Add the render.yaml below to your fork's root, then import the repo into Render.
